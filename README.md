# GoogleLock-Profile

Chrome extension (Manifest V3) สำหรับล็อกโปรไฟล์ Chrome ด้วยรหัสผ่าน ป้องกันคนอื่นเปิดดูอีเมลและเว็บที่ล็อกอินค้างไว้

## ฟีเจอร์

- ล็อกทุกครั้งที่เปิด Chrome / เข้าโปรไฟล์จากหน้า "Who's using Chrome?"
- **บล็อกที่ระดับเครือข่าย:** ระหว่างล็อก ทุกคำขอ http/https ถูกบล็อกด้วย `declarativeNetRequest` กฎปลดล็อกเป็น session rule ที่ Chrome ล้างทิ้งเองทุกครั้งที่ปิดเบราว์เซอร์ (รวมถึงตอนแครช) หลังรีสตาร์ทจึงถูกบล็อกตั้งแต่ก่อนส่วนขยายเริ่มทำงาน Gmail จะไม่โผล่แวบให้เห็น
- ล็อกทันทีเมื่อปิดหน้าต่างสุดท้ายของโปรไฟล์ หรือเมื่ออัปเดต/รีโหลดส่วนขยาย
- ล็อกอัตโนมัติเมื่อไม่ได้ใช้งาน (ตั้งเวลาได้) และเมื่อล็อกหน้าจอคอมพิวเตอร์
- กด `Alt+Shift+L` เพื่อล็อกทันที
- ระหว่างล็อก ทุกแท็บ (รวมถึง `chrome://extensions` และหน้าตั้งค่า) ถูกเปลี่ยนเป็นหน้าใส่รหัสผ่าน ปลดล็อกแล้วกลับไปหน้าเดิม
- รหัสผ่านเก็บเป็น hash (PBKDF2-SHA256, 310,000 รอบ)
- ใส่รหัสผิด 5 ครั้งต้องรอ เวลารอเพิ่มขึ้นเรื่อย ๆ (สูงสุด 15 นาที) ตัวนับไม่รีเซ็ตเมื่อปิด-เปิด Chrome

## ติดตั้ง

1. ดาวน์โหลดหรือ clone repo นี้ไปไว้ในโฟลเดอร์ที่คนอื่นแก้ไม่ได้ง่าย ๆ (เช่น ใต้ `C:\Program Files\` ซึ่งต้องใช้สิทธิ์ admin ถึงจะแก้ได้)
2. เปิด `chrome://extensions` แล้วเปิด **Developer mode**
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์ของ repo นี้
4. ตั้งรหัสผ่านในหน้าที่เปิดขึ้นมา

## ปิด DevTools (แนะนำมาก)

ถ้าเปิด DevTools (F12) บนหน้าล็อกได้ จะสั่งปลดล็อกได้โดยไม่ต้องใช้รหัส ส่วนขยายกันปุ่ม F12 และคลิกขวาไว้ระดับหนึ่ง แต่ยังเปิดผ่านเมนูได้ วิธีปิดจริงคือ Chrome policy:

- ดับเบิลคลิก `policy/enable-hardening.reg` แล้วกด Yes (ต้องใช้สิทธิ์ admin) แล้วปิด-เปิด Chrome ใหม่
- เช็กว่าใช้ได้ที่ `chrome://policy` ต้องเห็น `DeveloperToolsAvailability = 2`
- ⚠️ DevTools จะถูกปิดในทุกเว็บและทุกโปรไฟล์ ถ้าต้องการใช้ ให้รัน `policy/disable-hardening.reg`

## ให้ Chrome เปิดหน้าเลือกโปรไฟล์ก่อน

1. ต้องมีอย่างน้อย 2 โปรไฟล์ (เพิ่มโปรไฟล์แบบไม่ล็อกอินบัญชีได้)
2. เปิดสวิตช์ **Show on startup** ในหน้า "Who's using Chrome?"
3. ปิด **Continue running background apps…** ที่ `chrome://settings/system`
4. ไอคอน Chrome ที่ใช้เปิดต้องไม่มี `--profile-directory` ต่อท้ายในช่อง Target

## ข้อจำกัดที่ส่วนขยายแก้ไม่ได้

- ถ้าคนอื่นใช้บัญชี Windows ของคุณได้ (ไม่ได้ล็อกเครื่อง) เขาสามารถลบ/แก้โฟลเดอร์ส่วนขยาย, เปิด Chrome ด้วย `--disable-extensions` หรือก๊อปโปรไฟล์ออกไป ได้ → **ตั้งรหัสผ่าน Windows และกด Win+L ทุกครั้งที่ลุก**
- ระหว่างล็อก แถบบุ๊กมาร์กและรายการแนะนำในช่องที่อยู่ยังมองเห็นได้ (กดเปิดไม่ได้) ซ่อนแถบบุ๊กมาร์กได้ด้วย `Ctrl+Shift+B`
- อุปกรณ์อื่นที่ล็อกอิน Google ค้างไว้ → เปิดการยืนยันตัวตน 2 ขั้นตอน

ถ้าลืมรหัสผ่าน: เปิด Chrome ด้วย `--disable-extensions` แล้วลบส่วนขยายที่ `chrome://extensions` จากนั้นติดตั้งใหม่
